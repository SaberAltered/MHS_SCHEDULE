How Engineers Actually Write Chatbots

Instead of loose toy scripts with mutable globals, production AI systems use typed contracts, encapsulated session state, boundary regex matching, token budgeting, and resilient error recovery.

Step 1

RuleBasedEngine.ts

/**
 * Professional Rule-Based Keyword Matcher
 * Uses compiled regex word boundaries to avoid false substring matches.
 */
export interface RuleDefinition {
  id: string;
  patterns: RegExp[];
  response: string;
}

export interface EngineResult {
  success: boolean;
  response: string;
  matchedRuleId?: string;
}

export class RuleBasedEngine {
  private readonly rules: RuleDefinition[] = [];
  private readonly fallback: string;

  constructor(fallback: string = "I don't recognize that command.") {
    this.fallback = fallback;
  }

  /** Registers keywords with strict word-boundary (\b) matching */
  public addRule(id: string, keywords: string[], response: string): void {
    const patterns = keywords.map(kw => 
      new RegExp(`\\b${kw.replace(/[.*+?^${}()|[\]\\]/g, '\\$&')}\\b`, 'i')
    );
    this.rules.push({ id, patterns, response });
  }

  /** Evaluates user message against rules dictionary */
  public process(input: string): EngineResult {
    const normalized = input.trim();

    for (const rule of this.rules) {
      for (const pattern of rule.patterns) {
        if (pattern.test(normalized)) {
          return { success: true, response: rule.response, matchedRuleId: rule.id };
        }
      }
    }

    return { success: false, response: this.fallback };
  }
}
Step 2

LLMSessionManager.ts

/**
 * Professional LLM Multi-Turn Session Manager
 * Encapsulates message history, error rollback, and token budgets.
 */
export type Role = 'system' | 'user' | 'assistant';

export interface ChatMessage {
  role: Role;
  content: string;
}

export interface SessionConfig {
  apiKey: string;
  model?: string;
  systemInstruction: string;
}

export class LLMSessionManager {
  private history: ChatMessage[] = [];
  private readonly config: SessionConfig;

  constructor(config: SessionConfig) {
    this.config = { model: 'gpt-4o-mini', ...config };
    this.reset();
  }

  /** Dispatches prompt with accumulated context history */
  public async sendMessage(text: string, temp: number = 0.7): Promise<string> {
    this.history.push({ role: 'user', content: text });

    try {
      const res = await fetch("https://api.openai.com/v1/chat/completions", {
        method: "POST",
        headers: {
          "Content-Type": "application/json",
          "Authorization": `Bearer ${this.config.apiKey}`
        },
        body: JSON.stringify({
          model: this.config.model,
          messages: this.history, // Resends full context
          temperature: temp,       // Controls next-token sampling
          max_tokens: 300           // Budget token limit
        })
      });

      if (!res.ok) throw new Error(`API Error: ${res.statusText}`);

      const payload = await res.json();
      const reply = payload.choices[0].message.content;

      // Commit assistant turn to history for memory continuity
      this.history.push({ role: 'assistant', content: reply });
      return reply;
    } catch (err) {
      this.history.pop(); // Rollback unfulfilled user turn
      throw err;
    }
  }

  public reset(newPrompt?: string): void {
    this.history = [{
      role: 'system',
      content: newPrompt ?? this.config.systemInstruction
    }];
  }
}

Architectural Comparison: Rule-Based vs. Language Model

Dimension Rule-Based Chatbot Language Model (LLM) Why It Matters
Core Engine Keyword lookup & if/else statements Next-token probability neural network LLMs generalize to unfamiliar phrasing; rules fail instantly if words differ.
Conversation Memory None by default (stateless turn-by-turn) Simulated by sending full messages[] history Allows follow-ups ("What was my name?") without manual database schemas.
Behavior Steering Hardcoded strings System instructions & persona prompts Changing one sentence adapts tone, format, audience level, or persona.
Failure Mode "I don't understand" (Fallback) Hallucination (inventing plausible facts) LLMs optimize for fluency, not strict fact verification.
